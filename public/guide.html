Appointments & Document Requests
— step by step
7 Steps
1
Create Account LRN, name, Gmail, grade & strand → 8+ char password → 6-digit OTP · 1 Gmail = 1 account
2
Log In Gmail + password → student dashboard opens — i-check ang profile at LRN bago mag-book.
3
Book an Appointment Schedule → service, date, time slot → purpose → Confirm → appointment QR APT-xxxx
4
Request a Document Requests → + New Request → type, qty, purpose → confirm summary → request QR + REQ-xxxx
5
Track Your Requests My Requests: Pending → Under Review → Processing → Ready for Pickup → Completed · Show QR sa counter
6
Check Notifications Tap the bell icon — under review? processing? document ready? Alerted instantly in-app.
7
Profile & My QR Profile → LRN + profile picture · My QR STU-xxxx for identification · change password anytime (OTP)
Good to know:

Registrar's slots lang ang bookable · 1 slot = 1 student · APT = appointment, REQ = document · slow first load? Server is waking up — wait, then refresh.
